# PETITOSOS

MVP SaaS responsivo para entretenimento, bem-estar, comunidade, adoção e ajuda para pets.

## Stack
- React + TypeScript + Vite
- React Router
- Lucide Icons
- CSS responsivo

## Mascote
O mascote oficial está em `public/logo-mascote.png` e é usado como personagem principal da marca.

## Execução
```bash
npm install
npm run dev
```

> A primeira versão usa dados demo e localStorage para demonstrar autenticação, perfil do pet, progresso e comunidade. Supabase pode ser conectado posteriormente.
